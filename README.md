# Peetham — Where Stillness Takes Form

A consultation-led catalogue for Peetham: sacred home temple design, shaped by sacred geometry, material integrity and contemporary Indian living.

## What this is

A single-page, fully self-contained static site (`index.html` — all imagery embedded, no build step, no dependencies). It presents nine peetham designs, each in three finish studies, as concept visualizations. There is no checkout, pricing, or data collection: consultation happens directly with the studio.
